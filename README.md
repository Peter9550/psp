## 1. Введение и назначение

Первая лабораторная работа курса посвящена освоению базовых средств **HTML5** и **CSS3** без использования JavaScript. Цель — построить статичную вёрстку калькулятора (сетка кнопок 4×5 и поле результата) и страницы «Об авторе», объединить их общей навигацией и стилем оформления.

На этом этапе никакого интерактива — кнопки выглядят как кнопки, но не работают. Это специально: ЛР1 проверяет умение строить корректную семантическую разметку, верстать формы и сетки, оформлять элементы при помощи каскадных стилей. Логика появится в ЛР2.

## 2. Общая структура проекта

Проект состоит из трёх файлов:

```
psp/
├── calculator.html        — главная страница с калькулятором
├── about.html             — страница «Об авторе»
└── style.css              — общие стили обеих страниц
```

Никаких сборщиков, npm-зависимостей или серверов — открывается двойным кликом по `calculator.html`.

---

## 3. Описание разделов

В состав приложения входят следующие функциональные страницы:

* **Калькулятор (`calculator.html`)** — основная страница. Содержит блок результата (display) и сетку из 4×5 кнопок (цифры, операции, специальные клавиши `C`, `+/-`, `%`, `=`).
* **Об авторе (`about.html`)** — информационная страница с краткими сведениями о студенте, группе и описании проекта.
* **Общая стилевая база (`style.css`)** — единый файл стилей, подключаемый обеими страницами. Реализует тёмную тему с зелёным акцентом и фоновым изображением.

## 4. Вёрстка калькулятора

Сетка кнопок построена на **CSS Grid** — простой и предсказуемый способ выкладки 4 колонок без громоздкого `float` или `flexbox`-обёрток.

```html
<!-- calculator.html -->
<div class="calc-container">
  <div id="result" class="result">0</div>

  <div class="buttons-grid">
    <button class="my-btn secondary" id="btn_on_clear">C</button>
    <button class="my-btn secondary" id="btn_toggle_sign">+/-</button>
    <button class="my-btn secondary" id="btn_percentage">%</button>
    <button class="my-btn primary" id="btn_divide">/</button>
    <!-- ... 7 8 9 ×  4 5 6 −  1 2 3 + ... -->
    <button class="my-btn" id="btn_0">0</button>
    <button class="my-btn" id="btn_decimal">.</button>
    <button class="my-btn primary execute" id="btn_equals">=</button>
  </div>
</div>
```

```css
/* style.css */
.buttons-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);     /* → 4 равные колонки */
  gap: 10px;                                  /* → промежутки между кнопками */
}

.execute {
  grid-column: span 2;                       /* → кнопка "=" растягивается на 2 колонки */
  width: 100%;
}
```

Каждой кнопке заранее даётся уникальный `id` (`btn_1`, `btn_add`, `btn_equals` и т. д.) — это «контракт» с будущей JS-логикой ЛР2: скрипт найдёт элементы по id и навесит обработчики.

## 5. Стилизация и тема оформления

Цветовая схема: **тёмный фон + неоновый зелёный акцент** (`#00ff88`). Фон страницы — внешнее изображение через `background-image`, поверх — полупрозрачная панель калькулятора.

```css
body {
  background-image: url(https://img.freepik.com/.../background.jpg);
  background-size: cover;
  background-position: center;
  color: white;
  display: flex; justify-content: center; align-items: center;
  min-height: 100vh;
}

.calc-container {
  background: #2a2a2a;
  border: 2px solid #444;
  padding: 20px;
  border-radius: 15px;
  box-shadow: 0 20px 50px rgba(0,0,0,0.8);     /* → объёмная тень */
}

.result {
  background: #000;
  color: #00ff88;                               /* → неоново-зелёный текст результата */
  text-align: right;
  font-size: 2.5rem;
  font-weight: 200;
}

.my-btn:hover {
  background-color: #333;
  box-shadow: 0 0 15px rgba(0, 255, 136, 0.6);  /* → glow-эффект при наведении */
  border: 1px solid #00ff88;
  color: #00ff88;
  transform: scale(1.05);
}
```

Различные категории кнопок выделены классами:
* `.primary` — синие (арифметические операции `+ − × ÷`);
* `.secondary` — серые (вспомогательные `C`, `+/-`, `%`);
* без класса — обычный тёмный фон (цифры).

## 6. Навигационное меню

Сверху каждой страницы — единая навигация. Реализована как абсолютно позиционированная панель с `backdrop-filter: blur` для эффекта «стекла».

```html
<nav class="top-menu">
  <a href="calculator.html" class="active">Калькулятор</a>
  <a href="about.html">Об авторе</a>
  <a href="https://github.com/Peter9550/psp" target="_blank">GitHub</a>
</nav>
```

```css
.top-menu {
  position: absolute; top: 0; left: 0; width: 100%;
  padding: 20px;
  display: flex; justify-content: center; gap: 30px;
  background: rgba(0, 0, 0, 0.3);
  backdrop-filter: blur(10px);                  /* → размытие фона за панелью */
}

.top-menu a:hover {
  color: #00ff88;
  text-shadow: 0 0 10px #00ff88;                /* → светящийся текст при наведении */
}
```

Класс `.active` подсвечивает текущую страницу — выставляется в HTML вручную.
