## 1. Введение и назначение

Вторая лабораторная работа посвящена изучению **JavaScript** в браузерной среде: подключение скрипта к HTML, поиск элементов через `document.getElementById`, навешивание обработчиков на кнопки, обновление DOM (`innerHTML`), работа с глобальным состоянием через переменные.

В качестве базы взята вёрстка из ЛР1 (тёмная тема, сетка 4×5, навигация). Логика калькулятора реализована в отдельном файле `script.js`, который подключается к `calculator.html` через `<script src="script.js" defer>`. Каждой кнопке вёрстки заранее присвоен уникальный `id` — это «контракт» между HTML и JS.

## 3. Описание разделов

`script.js` логически разбит на блоки:

* **Состояние** — четыре глобальные переменные хранят весь контекст калькулятора.
* **`onButtonDiggitClick(digit)`** — общая функция ввода цифры или точки.
* **Обработчики цифр** — генерируются циклом для 10 цифр + точки.
* **Обработчики операций** — `+`, `−`, `×`, `÷` ставят `selectedOperator`.
* **Вспомогательные** — `C` (сброс), `+/-` (смена знака), `%` (процент).
* **`=`** — выполняет вычисление, помещает результат обратно в `a`.

---

## 4. Состояние калькулятора

Состояние хранится в **четырёх глобальных переменных**:

```js
let a = '';                  // → первый операнд (строка, чтобы хранить ведущие нули и точку)
let b = '';                  // → второй операнд
let selectedOperator = null; // → '+' / '-' / 'x' / '/' или null
let result = '';             // → последний посчитанный результат

const outputElement = document.getElementById('result');
// → ссылка на блок display из вёрстки ЛР1
```

Решение хранить операнды **строками**, а не числами, неслучайно: пользователь может начать ввод с точки, ввести `0.`, или поставить минус — это всё проще обработать на строках, чем на числах.

## 5. Ввод цифр и точки

Все 11 кнопок (10 цифр + `.`) обрабатываются одной общей функцией.

```js
function onButtonDiggitClick(digit) {
  let currentValue = (!selectedOperator) ? a : b;
  // → если оператор ещё не выбран → дополняем первый операнд a
  // → если уже выбран            → дополняем второй b

  if (currentValue === '0' && digit === '0') return;
  // → не позволяем ввести "00"

  if (currentValue === '0' && digit !== '.') {
    currentValue = digit;          // → "0" → "5"  (заменяем ведущий ноль)
  } else if (currentValue === '' && digit === '.') {
    currentValue = '0.';            // → "" → "0." (точка без целой части)
  } else {
    if (currentValue.length >= 11) return;       // → ограничение длины ввода
    if ((digit !== '.') || !currentValue.includes(digit)) {
      currentValue += digit;        // → дописываем (но точку не два раза)
    }
  }

  if (!selectedOperator) { a = currentValue; outputElement.innerHTML = a; }
  else                   { b = currentValue; outputElement.innerHTML = b; }
}
```

Подписка на кнопки — циклом по массиву id:

```js
const digitsId = ['btn_1', 'btn_2', ..., 'btn_0', 'btn_decimal'];
digitsId.forEach(function(id) {
  const button = document.getElementById(id);
  button.onclick = function() {
    onButtonDiggitClick(button.innerHTML);   // → берём текст кнопки как цифру
  }
});
// → ленивая регистрация: не дублируем 11 одинаковых onclick
// → button.innerHTML = '7' для кнопки <button>7</button>
```

## 6. Арифметические операции

Каждая операция запоминает выбранный оператор и **ничего не печатает** в display — пользователь должен видеть `a` до нажатия `=`.

```js
document.getElementById('btn_add').onclick = function() {
  if (a === '' || a === '-') return;          // → не сохраняем оператор без первого числа
  selectedOperator = '+';
};

document.getElementById('btn_minus').onclick = function() {
  if (!selectedOperator && a === '') {
    a = '-';                                   // → особый случай: "-5" вводится как унарный минус
    outputElement.innerHTML = a;
    return;
  }
  if (selectedOperator && b === '') {
    b = '-';                                   // → или унарный минус во втором операнде
    outputElement.innerHTML = b;
    return;
  }
  if (a === '' || a === '-') return;
  selectedOperator = '-';
};

document.getElementById('btn_multiply').onclick = function() { ...; selectedOperator = 'x'; };
document.getElementById('btn_divide').onclick   = function() { ...; selectedOperator = '/'; };
```

`btn_minus` сложнее остальных — он работает и как бинарный оператор вычитания, и как унарный минус (когда первый операнд ещё не начат). Это типичная проблема UX калькуляторов.

## 8. Вычисление и форматирование результата

```js
document.getElementById('btn_equals').onclick = function() {
  if (a === '' || a === '-' || b === '' || b === '-' || !selectedOperator) return;
  // → требуем валидные оба операнда и выбранный оператор

  switch (selectedOperator) {
    case '+': result = (+a) + (+b); break;
    case '-': result = (+a) - (+b); break;
    case 'x': result = (+a) * (+b); break;
    case '/': result = (+a) / (+b); break;
  }
  // → унарный плюс +a приводит строку к числу: +"3.14" → 3.14

  let resultString = result.toString();
  if (resultString.length > 12) {
    resultString = result.toExponential(5);
    // → длинный результат отображаем в экспоненциальной форме: 1.23456e+10
  }

  a = resultString;          // → результат становится новым "a" — можно сразу продолжить вычисление
  b = '';
  selectedOperator = null;
  outputElement.innerHTML = a;
};
```

Поведение «результат становится первым операндом» позволяет делать **накапливаемые вычисления**: `2 + 3 = 5`, потом нажимаешь `×`, потом `4` — получишь `5 × 4 = 20`. Это привычное поведение настольных калькуляторов.
